# NSTU Cover Page Generator 

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT) [![GitHub Stars](https://img.shields.io/github/stars/borhan008/nstu-coverpage-generator)](https://github.com/borhan008/nstu-coverpage-generator/stargazers)

**NSTU Cover Page Generator** is a minimalist, open-source web application for creating **assignment cover pages, lab report cover pages and indexes** without using Microsoft Word or other desktop software, since *2022*.

##  Live Demo

[Visit NSTU Cover Page Generator](https://borhan008.github.io/nstu-coverpage-generator/index.html)

##  Features

-  Assignment cover page generator (Bangla, English)
-  Index generator
-  Print-ready layouts
-  A4 paper format
-  Lightweight and fast
-  Works directly in the browser
-  Offline usage
-  Free and open source


## How to Use

1. Open the web application.
2. Select the type of document you want to create.
3. Enter the required information.
4. Generate your cover page or index.
5. Print it directly or save it as a PDF.

## Offline Usage

The application supports offline usage through **Progressive Web App (PWA)** caching.

For offline use, you may need to visit the required pages once while connected to the internet so that the browser can cache the necessary files.

## Install as an App

Since the application supports PWA, it can be installed on supported devices and used like a regular application.

### Android

Open the website in a supported browser and select **Install App** or **Add to Home Screen**.

### Desktop

Open the website in a supported browser and use the **Install** option from the browser's address bar or menu.

## Technologies

## Made for NSTU Students

This project was created primarily for students of **Noakhali Science and Technology University (NSTU)**.

The goal is to make creating academic documents such as assignment covers, lab report covers and indexes easier and faster.
